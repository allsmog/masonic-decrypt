# masonic-decrypt

Interactive browser demos for classical cryptography, steganography, visual
cryptography, and zero-knowledge proof concepts.

## Demos

| Demo | Topic | Entry point |
| --- | --- | --- |
| Encrypted QR | AES-CBC message decryption from URL data | `index.html` |
| Visual Cryptography | Two-share image reconstruction | `demo1/` |
| Steganography | Hidden message extraction from an image | `demo2/` |
| Pigpen Cipher | Masonic substitution cipher | `pigpen/` |
| Caesar Cipher | Shift cipher wheel | `caesar/` |
| Scytale Cipher | Transposition cipher | `scytale/` |
| Vigenere Cipher | Polyalphabetic substitution | `vigenere/` |
| Zero-Knowledge Proofs | Ali Baba cave and two-balls teaching demos | `zkp-cave/`, `zkp-balls/` |

Open `demos.html` for the full launcher.

## Notes

These are educational, client-side HTML demos. They are useful for explaining
crypto primitives and proof ideas, not for production cryptography.
